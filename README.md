# YemekSepeti-CX-CaseStudy
The goal of this project is to analyze customer support data, evaluate the performance of the "Self-Service" channel, and design actionable UX/process improvements to boost customer satisfaction (CSAT).

## 🛠️ Skills & Tools
* **Data Analysis & Visualization:** Python (Pandas, Matplotlib)
* **CX Analytics:** CSAT Evaluation, Root Cause Analysis
* **Product & Process Design:** UX Flow Optimization, Journey Mapping

---

## 🎯 Case Study Tasks & Solutions

### Task 1: Data Analysis & Insights
Analyzed a sample dataset of customer service interactions to evaluate channel performance.
* **CSAT Comparison:** Compared satisfaction scores between channels, revealing that Self-Service (2.78) slightly outperformed the Live Contact channel (2.73).
* **Root Cause Analysis:** Identified *Order Delays* and *Cancellation Requests* as the primary drivers of dissatisfaction in the Self-Service channel.
* **Actionable Recommendations:** Proposed data-driven strategies focusing on logistics tracking and order accuracy to prevent common friction points.

### Task 2: Process & UX Flow Optimization
Evaluated the user journey for a specific scenario (Order Delay) within the Help Center app.
* **UX Gap Analysis:** Identified that a lack of human empathy, confusing menu options, and missing real-time feedback were causing CSAT drops in the self-service flow.
* **Proposed Redesign:** 
  1. **Hybrid Support (AI + Human):** Implemented a seamless handover from an AI chatbot to a live agent for unresolved issues.
  2. **Streamlined Navigation:** Simplified the self-service menu with direct "Track Order" and "Delay Support" options to reduce click fatigue.
  3. **Proactive Transparency:** Suggested automated real-time status updates and compensation (e.g., coupons) before the user even initiates a complaint.
